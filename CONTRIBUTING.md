# Contributing

Contributions are welcome if they improve actual task clarity, evidence provenance, authorization boundaries, accessibility, or portability.

1. Open an issue describing the user job and UI problem.
2. Keep changes original and free of unlicensed assets.
3. Use the smallest suitable component; don't expand the demo into an unrelated product.
4. Run python3 scripts/check_repo.py and test affected UI controls in a browser.
5. Describe what was tested and what remains unverified.
6. Preserve visible labeling for fabricated demonstration data.

Please do not commit credentials, private data, screenshots from proprietary designs or unsupported engineering outcome claims.
